# V0.2 角色与反馈样板

这是当前状态说明，历史过程在外层开发记录中保留。本轮工程整理不推进任何新阶段，游戏名称待定。

## 当前实现

- 小角怪、独眼怪、兔耳怪支持四色；固定五官与身体／格底分层。兔耳内外随身体染色，不独立保色。
- 正式棋盘默认GPU染色，保留遮罩后端和纯格子对照。三种样板与8×10密集检查均可操作。
- 操作前冻结原同色共边区域，按最短连通距离确定前驱，前沿到共享边中点时向邻格交接，转弯从实际前驱方向染入；染色波最多1800ms，超出时等比压缩。各格染色完成后角色轻压回弹，原目标色邻队做轻量合群回应，不扩大染色集合。
- 三物种共享日常／开心表情装配。小角怪日常睁眼／原开心脸；独眼怪原圆瞳孔／白眼内笑眼；兔耳怪新睁眼／原笑眼。用户已表示三物种表情制作完成；不据此扩大为全部布局／手机性能验收。
- 身体回弹240ms，邻队回应140ms，最后活动帧后表情保持约350ms；表情余留不继续锁输入，重来／切布局／销毁复位。

## 验收边界

用户已认可此前静态角色、GPU染色过渡及基础动作方向。最新共享边接力、完整布局的连贯观感、全部取消路径和真机性能不据此视为通过。构建成功不证明GLSL实际编译、引擎导入或游戏播放成功。

举手姿势、完整舞台UI、通关演出、音效和平台发布未在本轮推进。

## 运行与代码定位

LayaAir3.2.9打开 `MonsterParty.laya`，等待导入并重新编译；选物种、开启角色动作后染色查看。当前入口为 `src/Main.ts`，模块见 [工程结构与维护约定](工程结构与维护约定.md)。

运行资源位于 `assets/characters/`，当前52张清单PNG；外层工具负责注册、打包、图集、构建与静态完整性检查。开发版本记录仅外层本地保留。
