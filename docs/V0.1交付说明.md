# V0.1 交付说明

日期：2026-10-26。用户在本轮明确表示“V0.1版本我审查通过”，实际操作验收由用户负责。自动验证由开发侧执行，两者分别记录；不推断用户逐项执行了哪些操作，也不虚构设备、帧率或测试日志。

## 完成范围

- 固定 LayaAir 3.2.9、纯 2D、TypeScript 独立工程。
- 四颜色选择、任意原同色共边区域染色；目标色、步数、成功与失败。
- 撤销恢复完整一步，重来恢复关卡初态，失败后允许重试。
- 三个可切换验证布局：连接边界、过渡排练、四色集合。
- 一种小角怪几何占位支持四色；身体染色，角和五官保持原色。
- 附加表现：连通距离接力、中心/斜向波前、亮边和短暂流光。当前是轻量图形近似，不是原参考 shader 的完整移植。

## 验证记录

开发过程中实际执行并通过：规则五样例、三套布局解法、帧逻辑替身检查、取消/销毁清理、渲染入口继承、挂载布局、入口模板与 HTTP 检查、IDE 配套 TypeScript 检查及独立构建。规则测试结果位于 `tests/rule-results.json`。

动画和挂载测试使用替身，不能等同于真实 WebGL 或真机验证。开发侧桌面截图多次超时的历史事实保留，不影响本轮记录用户明确给出的 V0.1 验收结论。

## 样板操作

1. 连接边界：默认选蓝，点击左黄队得到蓝蓝蓝黄黄，再点右黄队成功。
2. 过渡排练：依次选黄、红、蓝，每次点左上格，最后一步成功。
3. 四色集合：依次选黄、绿、蓝，每次点左上格，最后一步成功。可绕路体验失败及撤销重试。
