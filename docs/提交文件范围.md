## 已跟踪生成物的处理

若此次提交一并清理跟踪关系，在game仓库根目录执行：

```powershell
git rm -r --cached --ignore-unmatch library local browser bin/js bin/libs
git diff --cached --stat
```

第一条仅从Git索引移除，磁盘文件保留；删除记录会进入待提交区，用于让远端后续不再跟踪这些生成物。它不是删除本机缓存，也不是删除历史提交。本轮未替用户执行。
