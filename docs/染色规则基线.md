# 染色规则基线

- 先选色，再点击任意有效格子；选色不扣步，同色点击不扣步。
- 冻结被点击格操作前的原颜色，只遍历上下左右相连的原同色区域；对角不连。
- 一次有效染色扣一步。不穿过原有新颜色去寻找其他旧色区域。
- 黄黄蓝黄黄，选蓝点最左格，只得到蓝蓝蓝黄黄。原蓝可参与未来合群动作，但不能扩大本次染色范围。
- 动画期间拒绝下一次染色；所有本次覆盖完成后先判全盘目标色成功，再判步数耗尽失败。最后一步染对算成功。
- 全盘同色但颜色不是目标色，不算成功。
- 不移动、不消除、不掉落、不补充格子；怪兽外观不参与规则。
- 撤销恢复完整一步之前的棋盘和步数；当前动画期间禁用撤销。
- 重来和切关清除动画及旧回调；失败不会自动重置，可由玩家撤销或重来。
- 规则层 `src/Rules.ts` 与表现层分离，changed 为原染色对象，team 为最终连通队伍，不可混用。
